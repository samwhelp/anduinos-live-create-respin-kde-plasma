## Environment

* `Ubuntu 26.04`




## Start

Open Terminal , and run to install `git` and `make`

``` sh
sudo apt-get install git make
```




## Clone

Run to clone [anduinos-live-create-respin-kde-plasma](https://github.com/samwhelp/anduinos-live-create-respin-kde-plasma)

``` sh
git clone https://github.com/samwhelp/anduinos-live-create-respin-kde-plasma
```

Run to change dir `anduinos-live-create-respin-kde-plasma`

``` sh
cd anduinos-live-create-respin-kde-plasma
```

## Help

Run

``` sh
make
```

Or run

``` sh
make help
```

Show

```
Usage:
	$ make [action]

Example:
	$ make
	$ make help

	$ make prepare
	$ make build
	$ make clean

```




## Prepare

Run the following command to install the packages required to create an ISO file.

``` sh
make prepare
```




## Build

Only need to execute the following command to create an ISO file.

``` sh
make build
```




## Clean

Run to clean up previous builds.

``` sh
make clean
```
